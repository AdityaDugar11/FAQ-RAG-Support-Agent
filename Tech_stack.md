# Technology Stack

## Frontend
- **HTML5** - Structure
- **CSS3** - Styling (no framework)
- **Vanilla JavaScript** - Logic (no frameworks/libraries)
- **Fetch API** - HTTP requests

## Backend/Database
- **n8n** - Workflow orchestration
- **Airtable** - Data storage
- **Groq API** - LLM

## Deployment
- **Vercel** - Static hosting
- **GitHub** - Version control

## APIs Used
- **Airtable REST API** - Read records
- **n8n Webhook** - Execute workflow

## Browser Support
- Chrome, Firefox, Safari, Edge (all modern versions)
- Mobile responsive

## Dependencies
- None (zero NPM packages)
